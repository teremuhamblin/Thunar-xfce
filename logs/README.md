# Logs — THUNAR-XFCE
- Ce dossier contient les fichiers de journalisation du projet **THUNAR-XFCE**.

## Contenu
- `thunar-xfce.log` — journal principal du projet

## Objectif
Centraliser les événements, actions, erreurs et informations générées par les scripts et le TUI.

Les logs sont automatiquement écrits dans :
`var/ log/ thunar-xfce.log`

Ce dossier peut également contenir des archives ou des logs supplémentaires selon l’évolution du projet.
