 # Plugins
 >THUNAR-XFCE
- Ce dossier contient les plugins additionnels utilisés par le projet **THUNAR-XFCE**.

## Contenu
- Plugins Thunar activables/désactivables
- Scripts d’installation automatique
- Extensions personnalisées

## Objectif
Fournir un espace centralisé pour gérer, installer et maintenir les plugins utilisés par THUNAR-XFCE.

## Notes
Les plugins sont configurés via `config/plugins.conf` et chargés automatiquement par le TUI.
