 # TUI — Interface Textuelle Avancée

Ce dossier contient l’ensemble des éléments nécessaires à l’interface textuelle (TUI) du projet **THUNAR-XFCE**.

## Contenu
- `menu.sh` — Menu principal et sous-menus
- `colors.sh` — Palette de couleurs et styles
- `tui-advanced.sh` — Effets visuels avancés (cadres, transitions, animations)
- `banner.txt` — Bannière ASCII affichée au lancement

## Objectif
Fournir une interface claire, immersive et modulaire permettant de piloter les actions, plugins et configurations du projet THUNAR-XFCE.

## Notes
Les fichiers du TUI sont chargés automatiquement par `thunar-xfce.sh` et doivent être placés dans :
> opt/ thunar-xfce/ tui
- Interface optimisée pour une utilisation en terminal.
