# Config — THUNAR-XFCE
- Ce dossier contient les fichiers de configuration du projet **THUNAR-XFCE**.

## Contenu
- `thunar.conf` — paramètres généraux du projet
- `actions.conf` — configuration des actions personnalisées
- `plugins.conf` — gestion et activation des plugins

## Objectif
Centraliser et organiser toutes les configurations nécessaires au fonctionnement du TUI, des actions et des plugins.

Les fichiers sont chargés automatiquement par les scripts du projet.
