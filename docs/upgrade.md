🟩 2. UPGRADE.md (simple et court)

`markdown

Mise à jour — THUNAR-XFCE

Ce guide décrit comment mettre à jour THUNAR-XFCE vers une nouvelle version.

1. Mettre à jour le dépôt
`
cd THUNAR-XFCE
git pull
`

2. Réinstaller les composants
`
bash thunar-xfce-pack.sh
`

3. Recharger Thunar
`
thunar -q
`

4. Vérifier la version
Consulter le fichier CHANGELOG.md pour les nouveautés.

La mise à jour est terminée.
`
