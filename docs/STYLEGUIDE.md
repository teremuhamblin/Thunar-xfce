# Styleguide — THUNAR-XFCE

Ce document définit les conventions utilisées dans le projet.

## Bash
- Indentation : 4 espaces
- Noms de variables : MAJUSCULES pour les constantes, minuscules pour le reste
- Fonctions : `ma_fonction()`
- Commentaires : clairs, courts, utiles

## Fichiers
- `.sh` exécutables avec `#!/usr/bin/env bash`
- `.conf` en format INI simple
- `.md` minimalistes et structurés

## Logs
- Tous les scripts écrivent dans `/var/log/thunar-xfce.log`

## Objectif
Assurer une cohérence et une lisibilité maximale dans tout le projet.
