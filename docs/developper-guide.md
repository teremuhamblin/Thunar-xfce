# Developer Guide — THUNAR-XFCE

Ce document aide les développeurs à comprendre et étendre le projet.

## Structure
- `tui/` : interface textuelle
- `config/` : fichiers de configuration
- `plugins/` : plugins officiels et custom
- `actions/` : scripts Thunar
- `logs/` : journaux

## Développement
- Utiliser Bash propre et commenté
- Respecter le STYLEGUIDE.md
- Tester chaque script avant commit
